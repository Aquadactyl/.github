## What is Aquadactyl?

Aquadactyl is a free, open-source game server management ecosystem. Our main
project is an independent continuation of Pterodactyl, with Blueprint
integrated into the panel, managed releases, and a focused deployment
experience for hosting providers and communities.

We are building software that is practical to run, straightforward to
maintain, and shaped by the people who use it.

> Aquadactyl is an independent project and is not an official Pterodactyl or
> Blueprint release.

## Contributing

Issues, ideas, documentation improvements, and pull requests are welcome.
Please check the repository's `CONTRIBUTING.md` and existing issues before
starting larger changes.

When contributing:

- Keep changes focused and explain the motivation.
- Follow the conventions used by the repository.
- Include tests or documentation updates when they are relevant.
- Treat other contributors and users with respect.
